# Virtualization benchmarking tool

Measure startup time and footprint for different execution environments.

Note: there are a number of dependencies depending on the execution environments to evaluate. Check the `exp-run.sh` script for dependencies to install. For example: nodejs, python, java, firecracker, qemu, docker, etc.

- Building: `./exp-build.sh`

- Running: `./exp-run.sh`

- Plotting: `./exp-plot.sh`

Note: all results and plots will be placed in the `results` directory.
